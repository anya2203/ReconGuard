# ReconGuard

AI-powered financial reconciliation that investigates, resolves, and escalates exceptions.

## Problem

Finance-ops teams reconcile orders, payments, settlements, and invoices by hand every cycle. The easy majority can be matched with deterministic rules, but the ambiguous remainder requires investigation and carries a risk of incorrect resolution.

## Solution

ReconGuard is a hybrid reconciliation controller that uses deterministic matching wherever rules can decide correctly, routes genuinely ambiguous cases to an AI investigator with controlled read-only tools, and uses an independent policy engine to determine whether a case is safe to auto-resolve or must be escalated to a human.
